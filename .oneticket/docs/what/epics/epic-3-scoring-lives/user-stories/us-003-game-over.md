## Story
En tant que joueur, je veux voir un écran de game over quand je perds toutes mes vies, pour savoir que la partie est terminée.

## Expected Behavior
- Écran avec message "Game Over"
- Score final affiché
- Option de recommencer

## Acceptance Criteria
- Given: Le joueur perd sa dernière vie
- When: La balle sort
- Then: Écran Game Over affiché
- Then: Score final montré
- Then: Option "Rejouer" présentée
