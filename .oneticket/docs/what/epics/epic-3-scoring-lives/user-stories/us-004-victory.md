## Story
En tant que joueur, je veux voir un écran de victoire quand je détruis toutes les briques, pour célébrer ma réussite.

## Expected Behavior
- Écran avec message "Victoire"
- Score final affiché
- Option de recommencer

## Acceptance Criteria
- Given: Le joueur détruit la dernière brique
- Then: Écran Victoire affiché
- Then: "Toutes les briques détruites!"
- Then: Score final montré
- Then: Option "Rejouer" présentée
