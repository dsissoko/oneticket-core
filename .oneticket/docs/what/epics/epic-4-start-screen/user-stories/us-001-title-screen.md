# User Story

## Story
En tant que joueur, je veux voir un écran titre attractif avec le nom du jeu, pour comprendre que c'est un jeu Breakout.

## Expected Behavior
- Titre "BREAKOUT" affiché
- Design retro/arcade
- Animations subtiles (clignotement, glow)

## Acceptance Criteria
- Given: Le jeu charge
- Then: Écran titre affiché
- Then: Titre "BREAKOUT" visible
- Animation de fond présente
