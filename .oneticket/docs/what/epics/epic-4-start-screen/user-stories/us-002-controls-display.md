En tant que joueur, je veux savoir comment contrôler le jeu, pour pouvoir jouer immédiatement.

## Expected Behavior
- Instructions clavier: ← → pour bouger
- Instructions souris: mouvement horizontal
- Instructions tactiles (si applicable)

## Acceptance Criteria
- Given: Écran titre affiché
- Then: Instructions de contrôle visibles
- "Flèches ou Souris pour bouger"
- "Espace ou Clic pour lancer"
