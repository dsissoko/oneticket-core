## Story
En tant que joueur, je veux pouvoir démarrer le jeu facilement, pour commencer à jouer sans délai.

## Expected Behavior
- Appui sur Espace ou Clic commence le jeu
- Délai court avant le début
- Balle lancé automatiquement

## Acceptance Criteria
- Given: Écran titre affiché
- When: Joueur appuie sur Espace ou Clic
- Then: Compte à rebours 3-2-1
- Then: Balle launched
- Then: Jeu commence
