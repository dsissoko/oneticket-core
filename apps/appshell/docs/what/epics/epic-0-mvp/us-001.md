# User Story 001: File structure and project setup

## As a...
Product Owner

## I want...
A structure de fichiers avec propriété exclusive

## So that...
Les tâches parallèles ne provoquent pas d'erreurs de fusion

---

## Description

Établir la structure complète des répertoires pour le projet AppShell avec une propriété de fichier exclusive. Chaque répertoire doit être créé et organisé de manière à permettre aux tâches parallèles de travailler sans conflit de fusion.

La structure doit suivre le modèle décrit dans epic.md et permettre:
- Une propriété exclusive de chaque fichier (un fichier = une tâche)
- L'isolation des tâches parallèles
- La clarté de la destination pour chaque type de fichier

---

## Acceptance Criteria

```gherkin
Given je suis développeur travaillant sur AppShell
When je crée la structure du projet
Then les répertoires suivants doivent exister:
  | Répertoire | Objectif |
  | src/ | Code source principal |
  | src/screens/ | Composants écrans (propriété exclusive par écran) |
  | src/components/ui/ | Composants shadcn installés une seule fois |
  | src/hooks/ | Hooks personnalisés (propriété exclusive par hook) |
  | src/stores/ | Stores Zustand (vide en skeleton, .gitkeep) |
  | src/mocks/ | Handlers MSW et données mock |
  | src/lib/ | Utilitaires et clients |
  | src/styles/ | CSS global et variables de design |

And les fichiers root doivent être en place:
  | Fichier | Objectif |
  | .env.example | Variables d'environnement |
  | index.html | Entrée HTML |
  | package.json | Dépendances du projet |
  | tailwind.config.ts | Configuration Tailwind et tokens |
  | postcss.config.js | Configuration PostCSS |
  | tsconfig.json | Configuration TypeScript |
  | vite.config.ts | Configuration Vite |
  | vitest.config.ts | Configuration Vitest |
  | vitest.setup.ts | Setup Vitest |

And les répertoires vides doivent contenir des fichiers .gitkeep:
  | Répertoire | Motif |
  | src/stores/ | Convention Zustand (optionnel en skeleton) |
  | src/lib/schemas/ | Schemas Zod (optionnel en skeleton) |

And la propriété exclusive doit être documentée:
  - Un document OWNERSHIP.md explique qui possède quel répertoire/fichier
  - Les fichiers partagés (config, layout, tokens) sont marqués comme "Task 0"
  - Les fichiers de feature (screens, hooks) sont marqués comme "one task per file"
  - Les règles d'isolation entre tâches parallèles sont clairement énoncées
```

---

## Definition of Done

- ✅ Tous les répertoires listés existent et contiennent `.gitkeep` ou des fichiers
- ✅ Les fichiers root (config, env, html) sont en place
- ✅ Un document `OWNERSHIP.md` explique la propriété et les règles d'isolation
- ✅ `git status` montre une structure claire et bien organisée
- ✅ Pas de fichiers `.DS_Store` ou de répertoires cachés indésirables
- ✅ `npm install` fonctionne sans erreurs
- ✅ `npm run dev` démarre sans erreurs (si Vite est configuré)
