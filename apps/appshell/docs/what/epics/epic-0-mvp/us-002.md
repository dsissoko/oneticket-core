# User Story 002: AppLayout, Header, Footer structure

## As a...
Developer

## I want...
Un AppLayout avec Header, Outlet, Footer

## So that...
Je peux fournir une structure visuelle cohérente pour tous les écrans

---

## Description

Implémenter les composants structurels partagés:
- **AppLayout.tsx** — Wrapper principal pour tous les écrans (Header + Outlet + Footer)
- **Header.tsx** — Barre de navigation supérieure avec le nom de l'app, menu About&Help, et ThemeToggle
- **Footer.tsx** — Pied de page structuré mais vide, prêt pour contenu futur

Ces composants doivent être responsifs et fournir une structure visuelle cohérente à tous les écrans.

---

## Acceptance Criteria

```gherkin
Given je suis développeur créant l'AppLayout
When j'implémente les composants structurels
Then AppLayout.tsx doit:
  - Importer Header, Outlet (React Router), et Footer
  - Rendre <Header /> en haut
  - Rendre <Outlet /> au centre (contenu des écrans)
  - Rendre <Footer /> en bas
  - Appliquer des styles responsifs (pas de scroll horizontal sur mobile)

And Header.tsx doit:
  - Afficher le nom de l'app à gauche (depuis VITE_APP_NAME)
  - Le nom de l'app doit être cliquable → navigation vers /
  - Afficher un dropdown "About & Help" à droite avec:
    * Lien "About" → /about
    * Lien "Help" → /help
  - Afficher ThemeToggle à l'extrême droite
  - Utiliser des composants shadcn (Button, DropdownMenu)
  - S'afficher en largeur complète avec padding approprié

And Footer.tsx doit:
  - Être structuré (div avec classe appropriée)
  - Être vide (pas de contenu par défaut)
  - Être prêt pour recevoir du contenu dans les apps dérivées
  - S'afficher en largeur complète en bas de page

And le layout doit être responsive:
  - Header spans 100% de la largeur
  - Contenu principal (Outlet) est centré et lisible
  - Footer spans 100% de la largeur
  - Pas de scroll horizontal sur mobile/tablet
  - Ordre vertical correct sur petits écrans
```

---

## Definition of Done

- ✅ `src/layouts/AppLayout.tsx` existe et importe correctement
- ✅ `src/components/Header.tsx` existe et affiche le nom de l'app clickable
- ✅ `src/components/Footer.tsx` existe et est structuré
- ✅ `src/components/ThemeToggle.tsx` est importé par Header (même s'il n'existe pas encore)
- ✅ Le nom de l'app vient de `.env` (`VITE_APP_NAME`)
- ✅ React Router `<Outlet />` est utilisé pour le contenu
- ✅ Test manuel: cliquer sur le nom de l'app → navigation vers `/`
- ✅ Test manuel: dropdown "About & Help" → liens fonctionnels
- ✅ Layout responsive sur mobile (pas de scroll horizontal)
- ✅ Tous les composants utilisent shadcn/ui (Button, DropdownMenu, Separator si nécessaire)
