# User Story 003: React Router integration

## As a...
Developer

## I want...
React Router configuré avec 3 routes (/, /about, /help)

## So that...
La navigation fonctionne et tous les écrans sont accessibles

---

## Description

Configurer React Router v6 avec les trois routes initiales:
- `/` — HomeScreen (démontre la récupération de données avec MSW/React Query)
- `/about` — AboutScreen (description d'AppShell)
- `/help` — HelpScreen (quickstart de réutilisation)

AppLayout doit être appliqué à toutes les routes (via une route parent ou wrapping).

---

## Acceptance Criteria

```gherkin
Given je suis développeur configurant le routage
When j'implémente les routes React Router
Then App.tsx doit:
  - Importer BrowserRouter, Routes, Route, Outlet depuis react-router-dom
  - Définir une route parent AppLayout avec <Outlet />
  - Définir trois routes enfants:
    * path: "/" → element: <HomeScreen />
    * path: "/about" → element: <AboutScreen />
    * path: "/help" → element: <HelpScreen />
  - Appliquer AppLayout à toutes les routes
  - Supporter la navigation sans rechargement de page

And les liens de navigation doivent fonctionner:
  - Clic sur le nom de l'app → navigue vers /
  - "About" dans le dropdown → navigue vers /about
  - "Help" dans le dropdown → navigue vers /help
  - Les URLs reflètent l'état actuel (push state)
  - Le bouton back du navigateur fonctionne

And les écrans doivent rendre correctement:
  - HomeScreen, AboutScreen, HelpScreen s'affichent dans <Outlet />
  - Header et Footer demeurent visibles pendant la navigation
  - Pas d'erreurs console lors de la navigation
  - Page refresh sur une URL existante remet l'écran correct

And BrowserRouter doit être configuré:
  - Appelé une seule fois dans main.tsx autour de l'app entière
  - Basename configuré via vite.config.ts (si nécessaire pour GitHub Pages)
```

---

## Definition of Done

- ✅ `src/App.tsx` existe et exporte les routes
- ✅ React Router v6 est importé et utilisé correctement
- ✅ BrowserRouter est initialisé dans `main.tsx`
- ✅ Les trois routes (/, /about, /help) sont définies
- ✅ AppLayout est appliqué en tant que route parent
- ✅ Chaque route rend le bon écran
- ✅ Test manuel: naviger entre / → /about → /help
- ✅ Test manuel: cliquer sur "Home" (nom app) retourne à /
- ✅ Test manuel: bouton back du navigateur fonctionne
- ✅ Page refresh sur /about remet AboutScreen
- ✅ Pas d'erreurs console
- ✅ Les types React Router sont corrects (TypeScript)
