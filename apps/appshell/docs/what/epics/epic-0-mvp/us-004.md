# User Story 004: ThemeToggle (light/dark/system)

## As a...
User

## I want...
Switcher entre light/dark/system themes

## So that...
Je peux préférer mon thème et améliorer mon expérience visuelle

---

## Description

Implémenter le composant ThemeToggle qui offre 3 options:
1. **system** — suit la préférence du système d'exploitation (light/dark)
2. **light** — force le mode clair
3. **dark** — force le mode sombre

Le changement de thème doit être:
- **Réactif** — pas de rechargement de page
- **Instantané** — changement immédiat de l'apparence
- **Persistant** — la préférence est sauvegardée en localStorage

L'implémentation doit utiliser CSS custom properties et Tailwind's dark mode.

---

## Acceptance Criteria

```gherkin
Given je suis utilisateur regardant l'app en mode light
When je clique sur ThemeToggle et sélectionne "dark"
Then l'apparence doit changer immédiatement:
  - Les couleurs de background et foreground changent
  - Pas de rechargement de page
  - Le changement est instantané (< 100ms)
  - Les CSS variables sont appliquées correctement

And le système doit supporter les 3 modes:
  - "system": suit la préférence OS (light/dark)
  - "light": force le mode clair
  - "dark": force le mode sombre
  - Un mode doit être sélectionné par défaut

And la préférence doit persister:
  - La sélection est sauvegardée en localStorage
  - Au rechargement de page, la préférence précédente est restaurée
  - La clé localStorage peut être "app-theme" ou similar

And l'implémentation doit utiliser:
  - CSS custom properties (--background, --foreground, etc.)
  - Tailwind dark mode (classe "dark" sur <html>)
  - next-themes (ou équivalent Vite) pour gérer les états
  - HTML class mutation pour basculer le mode (pas localStorage seul)

And le UI doit être clair:
  - ThemeToggle affiche l'option sélectionnée
  - 3 options clairement visibles (menu dropdown ou buttons)
  - Icones cohérentes (lucide-react)
  - Accessible (labels ARIA, focusable)
```
