# User Story 006: MSW + React Query pattern

## As a...
Developer

## I want...
Un pattern MSW → React Query fonctionnel (dev-only)

## So that...
Je peux fetcher et cacher les données sans dépendre d'une API réelle

---

## Description

Implémenter la couche de récupération de données avec:
1. **MSW (Mock Service Worker)** — mock les API responses en développement seulement
2. **React Query** — gère le fetch, caching, et synchronisation des données
3. **useUsers() hook** — démontre le pattern avec un exemple concret
4. **HomeScreen** — affiche la liste des users dans des Cards

Le pattern doit être:
- **Dev-only** — MSW actif seulement quand `import.meta.env.DEV`
- **Production-safe** — zéro overhead en prod (code tree-shaken)
- **Type-safe** — TypeScript partout

---

## Acceptance Criteria

```gherkin
Given je suis développeur implémentant la récupération de données
When je configure MSW et React Query
Then MSW doit:
  - Être initialisé dans main.tsx via import.meta.env.DEV guard
  - Activer uniquement en développement
  - Intercepter les requêtes fetch sans modification du code
  - Retourner des réponses mock via mocks/handlers.ts

And le handler MSW doit:
  - Définir GET /api/users
  - Retourner un JSON avec liste d'utilisateurs:
    ```json
    {
      "data": [
        { "id": 1, "name": "Alice" },
        { "id": 2, "name": "Bob" },
        { "id": 3, "name": "Charlie" }
      ]
    }
    ```
  - Être situé dans mocks/handlers.ts
  - Supporter future extension (autres endpoints)

And React Query doit:
  - Être configuré avec QueryClientProvider dans main.tsx
  - Fournir un QueryClient singleton (lib/query-client.ts)
  - Supporter les DevTools (console)
  - Cacher les données automatiquement

And useUsers() hook doit:
  - Importer useQuery depuis @tanstack/react-query
  - Fetcher GET /api/users
  - Retourner { data, isLoading, error, isError }
  - Utiliser un queryKey unique: ['users']
  - Gérer les états loading/error

And HomeScreen doit:
  - Importer et utiliser useUsers()
  - Afficher un état loading (spinner ou skeleton)
  - Afficher les utilisateurs dans une liste de Cards:
    - Chaque Card affiche: id, name
    - Utilise composant shadcn/ui Card
  - Afficher un état error si la requête échoue
  - Afficher un état vide si aucun utilisateur

And l'intégration doit être transparente:
  - Zéro changement de code entre dev et prod
  - Pas de try/catch spécial pour MSW
  - Pas de configuration hardcodée d'API base URL
```

---

## Definition of Done

- ✅ MSW est installé via npm
- ✅ `mocks/browser.ts` initialise le worker
- ✅ `mocks/handlers.ts` définit GET /api/users
- ✅ `mocks/data/users.ts` fournit les données mock
- ✅ `main.tsx` initialise MSW avec `import.meta.env.DEV` guard
- ✅ `lib/query-client.ts` exporte un QueryClient singleton
- ✅ `main.tsx` wraps l'app dans QueryClientProvider
- ✅ `hooks/useUsers.ts` existe et utilise useQuery
- ✅ `HomeScreen.tsx` utilise useUsers() et affiche les Cards
- ✅ Test dev: `npm run dev` → HomeScreen affiche users mock
- ✅ Test prod: `npm run build && npm run preview` → pas d'erreurs MSW
- ✅ Pas de console errors/warnings
- ✅ React Query DevTools fonctionnent (optional mais préférable)
- ✅ Tous les fichiers ont types TypeScript complets
