# User Story 007: shadcn/ui components integration

## As a...
Developer

## I want...
shadcn/ui button, card, dropdown-menu, separator, form installés

## So that...
Je peux construire les écrans avec des composants accessibles et cohérents

---

## Description

Installer et intégrer les composants shadcn/ui via la CLI shadcn. Les composants doivent être:
1. **Installés dans le repo** — code dans `src/components/ui/`, pas npm
2. **Utilisables immédiatement** — importables et fonctionnels
3. **Configurés avec Tailwind** — styles via CSS variables et Tailwind classes
4. **Form intégré** — React Hook Form et Zod pour les formulaires

Les composants minimum:
- `button.tsx` — boutons réutilisables
- `card.tsx` — conteneurs pour contenu groupé
- `dropdown-menu.tsx` — menus déroulants
- `separator.tsx` — séparateurs visuels
- `form.tsx` — wrapper React Hook Form
- `input.tsx`, `label.tsx` — champs de formulaire

---

## Acceptance Criteria

```gherkin
Given je suis développeur installant shadcn/ui
When j'utilise la CLI shadcn pour installer les composants
Then la CLI doit:
  - Être configurée pour Vite (pas Next.js)
  - Créer components.json avec la bonne configuration
  - Installer les composants dans src/components/ui/

And les composants installés doivent:
  - Être présents dans src/components/ui/:
    * button.tsx
    * card.tsx
    * dropdown-menu.tsx
    * separator.tsx
    * form.tsx
    * input.tsx
    * label.tsx
  - Être importables via "src/components/ui/..."
  - Être basés sur Radix UI (accessible)
  - Supporter les styles via Tailwind

And chaque composant doit:
  - Être typé en TypeScript
  - Supporter les props HTML natives (className, etc.)
  - Supporter les variantes (size, variant, etc.)
  - Être customizable via Tailwind

And React Hook Form doit:
  - Être installé comme dépendance
  - Être intégré dans form.tsx
  - Fournir des wrappers <Form>, <FormField>, <FormControl>, etc.
  - Supporter la validation Zod

And Zod doit:
  - Être installé comme dépendance
  - Être utilisable pour valider les schémas de formulaires
  - Fournir des messages d'erreur clairs

And l'intégration doit:
  - Permettre d'importer les composants dans les écrans
  - Permettre de customizer les composants via Tailwind classes
  - Supporter le dark mode (via CSS variables)
  - Pas de conflits avec les tokens de design
```
