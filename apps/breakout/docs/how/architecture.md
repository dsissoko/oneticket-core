Crée le fichier architecture.md pour le projet Breakout. Stack technique : HTML5, CSS3, JavaScript vanilla (ES6+), aucune dépendance externe, persistence : localStorage uniquement. Composants principaux : Game (orchestration), GameBoard (physique, collision, rendu), Paddle (entité joueur), Ball (entité physique), Brick (entité mur), MenuController (UI menus), InputHandler (clavier/souris). Interfaces clés : event listeners du clavier (flèches gauche/droite), événements du menu (play, replay, quit), slider vitesse. Contraintes : vanilla JS uniquement, doit fonctionner sur tous navigateurs modernes. Utilise le template fourni dans .oneticket/templates/docs/how/architecture.md.
