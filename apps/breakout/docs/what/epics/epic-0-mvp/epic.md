# Epic 0: MVP Breakout

## Périmètre MVP

Le MVP Breakout est un système de jeu complet incluant les éléments suivants :

1. **Mur de 5 lignes de briques destructibles** - Structure de jeu principale avec briques arrangées en 5 rangées
2. **Balle avec physique de rebond** - Détection de collision et rebond sur murs, plafond, raquette et briques
3. **Raquette contrôlée aux flèches clavier** - Commandes gauche (←) et droite (→) pour le contrôle du joueur
4. **Gestion de 3 vies** - Système de vie avec game over après perte de 3 vies
5. **Condition de victoire** - Victoire automatique quand toutes les briques sont détruites
6. **Slider de vitesse de balle** - Contrôle de la vitesse de jeu dans le menu
7. **Menus basiques** - Interface utilisateur pour démarrer, rejouer et quitter le jeu

## Définition du Succès

L'MVP est considéré comme réussi quand le jeu est jouable de bout en bout avec tous les éléments ci-dessus fonctionnels et une expérience utilisateur cohérente.

## Critères d'Acceptation Globaux du MVP

- [ ] Le mur de 5 rangées de briques est correctement affiché au démarrage
- [ ] La balle rebondit correctement sur tous les éléments (murs, plafond, raquette, briques)
- [ ] La raquette répond aux commandes clavier gauche/droite
- [ ] Le système de 3 vies fonctionne correctement
- [ ] Game over s'affiche et arrête le jeu après perte de 3 vies
- [ ] La victoire s'affiche quand toutes les briques sont détruites
- [ ] Le slider de vitesse affecte correctement la vitesse de la balle
- [ ] Les menus (démarrer, rejouer, quitter) sont fonctionnels et accessibles
- [ ] Le jeu se relance correctement après rejouer
- [ ] L'expérience de jeu est fluide et sans bugs majeurs
