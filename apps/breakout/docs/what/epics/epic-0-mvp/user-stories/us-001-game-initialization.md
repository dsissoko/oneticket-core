# User Story

## Story

Crée la user story us-001 pour l'initialisation du jeu. Format Mike Cohn : En tant que joueur, je veux que le jeu s'initialise avec un mur de briques et une balle au lancement, afin de pouvoir commencer à jouer.

## Expected Behavior

The game board displays 5 rows of bricks and a ball positioned above the paddle when the user clicks 'Play'.

## Acceptance Criteria

Given the game starts, When the user clicks 'Play', Then the game board displays 5 rows of bricks and a ball positioned above the paddle.
