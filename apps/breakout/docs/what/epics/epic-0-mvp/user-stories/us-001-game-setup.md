# User Story

## Story
En tant que joueur, je veux accéder à l'application Breakout avec un environnement de jeu proprement structuré en HTML/CSS/JS, afin que le jeu soit prêt à jouer.

## Expected Behavior
- Application chargeable dans un navigateur moderne
- Écran de titre/menu visible
- Canvas ou zone de jeu visible
- Pas d'erreurs console au chargement
- CSS de base appliquée (couleurs, dimensions appropriées)

## Acceptance Criteria
- [ ] Projet initialisé avec index.html, style.css, script.js
- [ ] Canvas (ou conteneur DOM) pour le jeu visible
- [ ] Menu principal affiché (boutons start, quit)
- [ ] Application charge sans erreur JavaScript
- [ ] Responsive design basique (adapté à la majorité des écrans)
