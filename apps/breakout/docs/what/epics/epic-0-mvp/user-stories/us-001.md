Titre: US-001 — Initialiser le jeu avec l'aire de jeu

Histoire utilisateur:
En tant que joueur, je veux voir l'aire de jeu au démarrage, afin de commencer à jouer.

Comportement attendu:
- L'aire de jeu s'affiche avec des dimensions fixes (ex: 800x600 ou similaire)
- Le canvas ou container est rendu et prêt à recevoir les éléments du jeu
- Les briques sont arrangées en 5 lignes

Critères d'acceptation:
- L'aire de jeu s'affiche correctement
- Les briques sont visibles
- L'interface est réactive
