# User Story

## Story
En tant que joueur, je veux déplacer la raquette avec les flèches gauche et droite du clavier, afin de contrôler la position pour bloquer la balle.

## Expected Behavior
- Flèche gauche déplace la raquette à gauche
- Flèche droite déplace la raquette à droite
- Raquette reste dans les limites de l'écran
- Déplacement fluide et réactif
- Aucun décalage ou lag perceptible

## Acceptance Criteria
- [ ] Event listeners sur les touches flèches
- [ ] Raquette se déplace à vitesse constante et prévisible
- [ ] Raquette ne sort pas de l'écran
- [ ] Contrôle immédiat sans délai
- [ ] Souris n'affecte pas le mouvement raquette
