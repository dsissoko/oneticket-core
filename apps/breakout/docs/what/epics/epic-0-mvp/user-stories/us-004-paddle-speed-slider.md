# US-004 — Add Paddle Speed Control Slider

## Goal

Implement a slider UI control that allows players to adjust paddle movement speed in real-time during gameplay.

## Acceptance Criteria

- Slider input control is visible and accessible to the player
- Slider range is 0.5x to 2.0x base paddle speed
- Speed adjustment applies immediately to paddle movement
- Current speed multiplier is displayed to the player
- Slider responds smoothly to input without lag
- Paddle movement remains responsive with all slider positions
- Default position sets paddle to 1.0x base speed

## Business Value

Adjustable speed control enables accessibility for different player skill levels and provides agency in gameplay difficulty. This feature transforms a static game into one that adapts to player preference.
