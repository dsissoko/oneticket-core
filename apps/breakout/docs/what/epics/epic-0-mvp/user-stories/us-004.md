Titre: US-004 — Gérer l'état du jeu (démarrage, jeu, fin)

Histoire utilisateur:
En tant que joueur, je veux pouvoir démarrer, relancer et quitter le jeu via un menu, afin de contrôler mon expérience de jeu.

Comportement attendu:
- Un menu d'accueil s'affiche au démarrage
- Bouton "Démarrer" lance le jeu
- Bouton "Rejouer" redémarre après une fin
- Bouton "Quitter" ferme le jeu
- Un écran "Victoire" s'affiche quand toutes les briques sont détruites
- Un écran "Défaite" s'affiche quand les vies sont épuisées

Critères d'acceptation:
- Les états de jeu sont gérés correctement
- Les transitions entre états sont fluides
- La souris fonctionne correctement dans les menus
