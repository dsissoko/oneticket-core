Créer la user story us-005 pour l'écran de game over. Story : 'En tant que joueur casual, je veux voir un écran de game over clair quand je perds, avec mon score final et l'option de recommencer, afin de savoir si je veux essayer à nouveau.' Critères d'acceptation (Gherkin) : Quand la balle sort du bas du canvas, l'écran de game over s'affiche. L'écran affiche 'Game Over', le score final en gros caractères, et un bouton 'Rejouer'. Quand je clique sur 'Rejouer', une nouvelle partie commence avec un score à 0 et toutes les briques restaurées.
