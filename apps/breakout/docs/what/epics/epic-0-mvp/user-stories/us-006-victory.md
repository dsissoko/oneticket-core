Créer la user story us-006 pour l'écran de victoire. Story : 'En tant que joueur casual, je veux voir un écran de victoire exaltant quand j'ai détruit toutes les briques, avec mon score final et l'option de rejouer, afin de célébrer ma victoire.' Critères d'acceptation (Gherkin) : Quand toutes les briques sont détruites, l'écran de victoire s'affiche. L'écran affiche 'Victory!', le score final en gros caractères, et un bouton 'Rejouer'. Quand je clique sur 'Rejouer', une nouvelle partie commence avec un score à 0 et toutes les briques restaurées.
