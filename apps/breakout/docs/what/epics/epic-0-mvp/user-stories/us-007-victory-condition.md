# User Story

## Story
En tant que joueur, je veux gagner la partie en détruisant toutes les briques, afin d'avoir un objectif clair et une récompense de victoire.

## Expected Behavior
- Destruction dernière brique déclenche victoire
- Affichage message victoire
- Partie pause, options (rejouer/quitter) affichées
- Pas de continuation du jeu après victoire

## Acceptance Criteria
- [ ] Comptage briques mis à jour après destruction
- [ ] Vérification 0 briques = victoire
- [ ] Transition victoire (pause jeu, affichage message)
- [ ] Menu victoire avec options
- [ ] Pas de continuation de jeu
