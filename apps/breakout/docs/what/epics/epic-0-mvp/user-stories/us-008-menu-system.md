# User Story

## Story
En tant que joueur, je veux accéder à des menus pour démarrer une partie, rejouer ou quitter l'application, afin de contrôler le flux du jeu.

## Expected Behavior
- Menu principal affiché au démarrage
- Bouton "Démarrer" lance la partie
- Menu "Game Over" apparu avec "Rejouer" et "Quitter"
- Menu "Victoire" apparu avec "Rejouer" et "Quitter"
- Souris navigable sur menus
- Clavier n'affecte pas menus (réservé raquette)

## Acceptance Criteria
- [ ] Menu principal avec boutons (Start, Quit)
- [ ] Clic Start démarre la partie
- [ ] Clic Quit ferme/quitte l'appli
- [ ] Menu game over avec options
- [ ] Menu victoire avec options
- [ ] Clics souris gérés correctement
- [ ] Menus visibles et bien positionnés
