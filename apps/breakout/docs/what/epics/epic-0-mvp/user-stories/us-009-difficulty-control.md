# User Story

## Story
En tant que joueur, je veux ajuster la vitesse de la balle via un slider du menu avant de démarrer, afin de choisir la difficulté qui me convient.

## Expected Behavior
- Slider visible dans le menu principal
- Slider plage très lente → très rapide
- Valeur actuelle affichée (numérique ou visuelle)
- Changement slider affecte immédiatement vitesse balle
- Réglage persiste pour la partie lancée

## Acceptance Criteria
- [ ] Slider HTML implémenté
- [ ] Plage min/max cohérente (ex: 1-10)
- [ ] Valeur affichée et mise à jour en temps réel
- [ ] Vitesse balle ajustée selon slider
- [ ] Slider accessible et ergonomique
- [ ] Pas de lags sur interaction slider
