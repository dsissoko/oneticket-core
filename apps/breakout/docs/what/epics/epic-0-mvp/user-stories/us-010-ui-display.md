## Story
En tant que joueur, je veux voir les informations de jeu (score, vies, briques restantes) affichées en temps réel pendant la partie, afin de suivre ma progression.

## Expected Behavior
- Score affiché pendant la partie
- Nombre de vies restantes affiché
- Nombre de briques restantes affiché
- Informations mises à jour en temps réel
- Positionnement clair et lisible
- Contraste adequate pour la lisibilité

## Acceptance Criteria
- [ ] Éléments UI rendus (texte/nombres)
- [ ] Score mis à jour après destruction brique
- [ ] Vies mise à jour après perte
- [ ] Briques comptées et affichées
- [ ] Pas de confusion visuelle
- [ ] Layout stable (pas de saut)
