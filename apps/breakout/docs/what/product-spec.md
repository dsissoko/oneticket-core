Créer le fichier product-spec.md pour le jeu Breakout. Le produit s'appelle 'Breakout'. C'est un jeu de casse-briques classique pour divertir les joueurs casual de tous âges. Les principales capacités sont : (1) raquette contrôlable au clavier/souris, (2) balle avec physique simple et rebonds, (3) briques destructibles, (4) système de score persistant, (5) écran de game over et écran de victoire. L'utilisateur principal est un joueur casual (single user, pas de multijoueur). Les règles métier : la balle rebondit sur la raquette et les briques, la raquette se déplace horizontalement, la destruction d'une brique ajoute des points, la victoire se déclenche quand toutes les briques sont détruites, le game over quand la balle sort du bas de l'écran.
