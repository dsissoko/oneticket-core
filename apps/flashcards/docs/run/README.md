# Run

The `run/` section describes how the system operates in runtime environments.

It defines:
- infrastructure,
- orchestration,
- runtime topology,
- networking,
- scalability,
- observability,
- resilience,
- security operations,
- operational procedures.

This section focuses on keeping the system operational, observable, secure, and scalable.

Typical artifacts may include:
- infrastructure-as-code,
- Kubernetes manifests,
- Docker Compose stacks,
- monitoring configuration,
- alerting rules,
- backup strategies,
- operational runbooks.

The `run/` section is concerned with operating the system after delivery.
