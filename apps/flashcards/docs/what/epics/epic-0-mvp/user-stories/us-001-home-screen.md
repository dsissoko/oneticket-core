# US-001 — Home Screen Theme and Mode Selection

## Story

As a learner, I want to select a theme and learning mode so that I can start a study session.

## Expected Behavior

Home screen displays a theme picker showing "World Capitals" and a mode selector showing "flip". A Start button navigates the user to /session when tapped.

## Acceptance Criteria

- Theme picker shows World Capitals
- Mode selector shows flip
- Start button navigates to /session
