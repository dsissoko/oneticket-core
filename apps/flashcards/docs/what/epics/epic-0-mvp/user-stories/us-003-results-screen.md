# US-003 — Results Screen Session Score

## Story

As a learner, I want to see my session score and replay option so that I can track my learning progress.

## Expected Behavior

Results screen displays the session score as X/Y known (e.g., 7/10). A replay button restarts the session with the same theme and mode. A back to home option returns to the home screen.

## Acceptance Criteria

- Score displays X/Y known
- Replay button restarts session
- Back to home option
