# US-008 — Bilingual FR/EN Note Names

## Story

As a bilingual music learner, I want to see both French (do/ré/mi) and English (C/D/E) note names so that I can learn in my preferred language.

## Expected Behavior

Card back shows both FR and EN note names. FR/EN mapping: do→C, ré→D, mi→E, fa→F, sol→G, la→A, si→B. Supports whole/half/quarter note durations.

## Acceptance Criteria

- Given I view the card back, then both French and English note names are displayed.
- Given a note name, then the FR/EN mapping is correct: do→C, ré→D, mi→E, fa→F, sol→G, la→A, si→B.
- Given notes of different durations (whole, half, quarter), then the bilingual display supports all duration types.
