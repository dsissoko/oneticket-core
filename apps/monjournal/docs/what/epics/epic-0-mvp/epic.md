# Epic 0 — MVP: MonJournal Thought Management System

## Goal

Establish the MVP with complete thought management capabilities: create, read, edit, delete, tag, filter, search, and surprise button functionality.

## Business Value

Enable users to capture and explore their personal thoughts simply and elegantly, with intuitive organization and discovery features.

## Scope

All capabilities described in product-spec.md:
- **Core CRUD Operations** — Create, read, edit, delete thoughts (max 200 characters)
- **Tagging System** — Add, modify, remove tags on thoughts; case-insensitive tag management
- **Search & Filtering** — Full-text search by keyword and filter by selected tags
- **Surprise Feature** — Random thought discovery from the complete history
- **Unified Interface** — Single-page application with creation form, thought stream, search, filters
- **Local Storage** — All data persisted in browser localStorage
- **Markdown Support** — Basic markdown rendering (bold, italic, lists)
- **Responsive Design** — Mobile-friendly layout
