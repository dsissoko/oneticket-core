# US-001 — Create Thought

## Story

En tant qu'utilisateur, je veux créer une nouvelle pensée avec un texte en markdown (max 200 chars) et la date courante

## Expected Behavior

Le formulaire accepte du markdown, limite la saisie à 200 caractères, crée la pensée avec timestamp automatique

## Acceptance Criteria

- Je peux saisir du texte markdown dans un champ de formulaire
- Le système limite automatiquement à 200 caractères
- Au soumettre, la pensée est créée avec la date/heure courante
- La nouvelle pensée apparaît en haut de la liste
