# US-003 — Edit and Delete a Thought

## Story

En tant qu'utilisateur, je veux éditer ou supprimer une pensée existante

## Expected Behavior

Chaque pensée offre des actions d'édition et suppression. L'édition réouvre le formulaire, la suppression demande confirmation.

## Acceptance Criteria

- Chaque pensée affiche des boutons d'édition et suppression
- Cliquer éditer réouvre le formulaire avec le texte/tags actuels
- Cliquer supprimer demande confirmation avant suppression
- Après édition ou suppression, la liste se met à jour
- Les timestamps de création restent inchangés, seul le contenu change
