# US-004 — Tag Thoughts

## Story

En tant qu'utilisateur, je veux ajouter des tags à une pensée pour l'organiser et la catégoriser

## Expected Behavior

Lors de la création ou édition, un champ permet d'ajouter des tags séparés par des virgules ou des espaces. Les tags sont affichés sous chaque pensée.

## Acceptance Criteria

- Je peux ajouter zéro, un ou plusieurs tags lors de la création/édition
- Les tags s'affichent sous le texte de la pensée
- Un même tag peut être utilisé sur plusieurs pensées
- Éditer une pensée permet de modifier ses tags
