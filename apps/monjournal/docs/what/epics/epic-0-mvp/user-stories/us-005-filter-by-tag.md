# US-005 — Filtrer les pensées par tag

## Story

En tant qu'utilisateur, je veux filtrer les pensées par tag pour voir seulement celles qui m'intéressent

## Expected Behavior

Une section de filtres affiche tous les tags disponibles. Cliquer sur un tag filtre la liste pour n'afficher que les pensées avec ce tag

## Acceptance Criteria

- Tous les tags disponibles sont listés
- Cliquer sur un tag filtre la liste
- Je peux sélectionner plusieurs tags (ET logique)
- Un bouton « Effacer filtres » réinitialise la vue complète
- L'affichage se met à jour immédiatement
