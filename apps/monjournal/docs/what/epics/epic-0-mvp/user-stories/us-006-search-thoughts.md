# US-006 — Search Thoughts by Keyword

## Story

En tant qu'utilisateur, je veux rechercher des pensées par mot-clé pour trouver rapidement ce qui m'intéresse

## Expected Behavior

Un champ de recherche permet de taper un mot-clé. La liste se filtre pour afficher seulement les pensées contenant ce mot-clé

## Acceptance Criteria

- Un champ de recherche texte est visible en haut de la page
- La recherche est insensible à la casse
- La liste se met à jour en temps réel pendant la saisie
- La recherche fonctionne sur le contenu des pensées (pas les tags)
- Un champ vide affiche toutes les pensées
