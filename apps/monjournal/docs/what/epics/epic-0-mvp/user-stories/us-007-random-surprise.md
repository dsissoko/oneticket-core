# US-007 — Random Surprise Button

## Story

En tant qu'utilisateur, je veux cliquer sur un bouton surprise pour voir une pensée aléatoire de ma liste

## Expected Behavior

Un bouton surprise est affiché. Au clic, la liste est filtrée pour ne montrer qu'une pensée choisie aléatoirement parmi toutes les pensées actuellement visibles

## Acceptance Criteria

- Un bouton « Surprise » est visible en haut de la page
- Cliquer affiche une seule pensée choisie aléatoirement
- La sélection respecte les filtres actuels (tag, recherche)
- Recliquer affiche une autre pensée aléatoire
- Un bouton « Fermer surprise » ou « Afficher tout » revient à la liste complète
