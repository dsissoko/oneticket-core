# Epic 0 — MVP Space Invaders

## Goal

Deliver a playable Space Invaders game with core arcade mechanics — alien wave, player cannon, projectiles, shields, scoring, game states — in a responsive React+Vite+TypeScript SPA deployed on GitHub Pages.

## Business Value

Provides a complete, faithful recreation of the classic arcade experience accessible from any modern browser with no installation required.

## Scope

Canvas-based rendering, responsive layout, keyboard and touch controls, 5x11 alien grid with movement, dual projectile system, 4 destructible shields, score display with localStorage best score, game state machine (menu/playing/game over/victory).
