# EPIC-1: Fondations et physique du jeu

## Description
Mise en place des fondations techniques et du système de physique de base pour le jeu de balle.

## User Stories

### US-1.1: Structure HTML/Canvas
**Description:** Créer la structure HTML de base et initialiser un canvas pour le rendu du jeu.

**Critères d'acceptation:**
- Un fichier HTML principal est créé avec un canvas
- Le canvas est accessible et dimensionné correctement
- Un script JavaScript de base charge et initialise le canvas
- La page s'affiche correctement dans le navigateur

### US-1.2: Physique de base
**Description:** Implémenter le système de physique de base pour simuler la gravité et le mouvement.

**Critères d'acceptation:**
- Un moteur de physique basic est implémenté
- La gravité affecte les objets
- Le mouvement des objets est calculé correctement à chaque frame
- Les objets répondent aux forces appliquées

### US-1.3: Balle et rebonds
**Description:** Créer la balle du jeu et implémenter le système de rebonds contre les murs.

**Critères d'acceptation:**
- Une balle est visible sur le canvas
- La balle se déplace selon la physique du jeu
- La balle rebondit sur les murs de manière réaliste
- L'élasticité des rebonds est paramétrable
