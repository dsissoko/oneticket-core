# EPIC-4: États du jeu et écrans

## Description

Cet epic définit les différents états du jeu et les écrans associés pour améliorer l'expérience utilisateur. Il couvre l'écran d'accueil, l'écran de pause, l'écran de victoire et l'écran de game over.

---

## User Story 4.1: Accueil et pause

### Description
En tant que joueur, je souhaite avoir un écran d'accueil clair et un système de pause fonctionnel pour contrôler le flux du jeu.

### Critères d'acceptation
- [ ] L'écran d'accueil affiche un titre et des boutons "Jouer" et "Quitter"
- [ ] Le joueur peut mettre le jeu en pause en appuyant sur une touche dédiée
- [ ] L'écran de pause affiche le message "Jeu en pause" et des options pour reprendre ou quitter
- [ ] Tous les éléments du jeu sont figés lors de la pause
- [ ] La reprendre le jeu restaure l'état précédent

---

## User Story 4.2: Écran victoire

### Description
En tant que joueur, je souhaite voir un écran de victoire clair et motivant quand je complète le niveau.

### Critères d'acceptation
- [ ] L'écran de victoire s'affiche automatiquement quand les objectifs sont atteints
- [ ] L'écran affiche un message de félicitations
- [ ] Le score ou le temps de victoire est affiché
- [ ] Des boutons "Rejouer" et "Retour au menu" sont présents
- [ ] Une animation ou effet visuel célèbre la victoire

---

## User Story 4.3: Écran game over

### Description
En tant que joueur, je souhaite voir un écran de game over clair quand je perds, avec options pour rejouer ou revenir au menu.

### Critères d'acceptation
- [ ] L'écran de game over s'affiche automatiquement quand les conditions d'échec sont atteintes
- [ ] L'écran affiche un message d'échec approprié
- [ ] Le score final ou l'étape de progression est affiché
- [ ] Des boutons "Rejouer" et "Retour au menu" sont présents
- [ ] Un effet visuel ou sonore indique l'échec du jeu

---
