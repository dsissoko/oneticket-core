US-004 — Complete Study Flow

Story

Section titled “Story”

As a learner, I want to go through Home → Session → Results → replay so that I can study flashcards continuously.

Expected Behavior

Section titled “Expected Behavior”

All three screens (Home, Session, Results) link correctly in the flow. Session data persists in localStorage across screen transitions. Replay resets the session state while maintaining theme and mode selection.

Acceptance Criteria

Section titled “Acceptance Criteria”
  • All 3 screens link correctly
  • Session data persists in localStorage
  • Replay resets session
