Slice 11 — Beginner Solfège Dataset

Goal

Section titled “Goal”

Create a curated beginner solfège card dataset with ~20 cards, each containing 5-15 notes in treble clef, ordered by increasing difficulty.

Related Epics

Section titled “Related Epics”

Epic 2 — Animated Score Learning

Related User Stories

Section titled “Related User Stories”

US-011 — Beginner Solfège Card Dataset

Dependencies

Section titled “Dependencies”
  • Slice 6 — Solfège Card Data (data structure and bilingual naming already defined)

Impacted Components

Section titled “Impacted Components”
ComponentChange

src/data/themes/index.tsModified — register solfege-beginner theme

Data Schema

Section titled “Data Schema”

Dataset Structure

Section titled “Dataset Structure”
Card RangeNotes per CardDifficulty Focus
Cards 1–55 notesStaff lines only (E4, G4, B4, D5, F5)
Cards 6–107 notesStaff spaces only (F4, A4, C5, E5) + lines
Cards 11–1510 notesMixed lines and spaces, quarter + half notes
Cards 16–2012–15 notesIntroduces ledger lines (C4, B3), whole notes

Constraints

Section titled “Constraints”
  • All notes in treble clef, C4–B5 range
  • Note durations: whole (w), half (h), quarter (q) only
  • Bilingual names on every note: { en: "C", fr: "do" }
  • Cards ordered by increasing difficulty

Observability Impact

Section titled “Observability Impact”
  • None — data-only change
