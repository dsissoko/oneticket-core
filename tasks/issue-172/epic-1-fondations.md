# Epic 1 : Fondations et Rendu

## Description
Mise en place de l'infrastructure de base du jeu Breakout : structure HTML, canvas, contexte 2D et boucle de rendu.

## Contenu du fichier
Créer un fichier HTML avec :
- Un canvas 800x600px
- CSS minimal pour centrer le canvas
- Boucle de jeu avec requestAnimationFrame
- Système de rendu (effacer et redessiner le canvas)
- Structure de base pour les entités du jeu

## Critères d'acceptation
- Canvas affiché et fonctionnel
- Boucle de jeu tourne à 60fps
- Écran noir nettoyé à chaque frame
- Pas d'erreurs console
